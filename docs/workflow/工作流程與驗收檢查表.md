## 資料與安全

- [ ] Repo 與 Pages 都是公開的（2026-11-05 起）：提交與發布前已確認沒有未經核准公開的真實資料或機密內容。
- [ ] 不提交帳密、Token、私人客戶名單或未核准機密資料。
- [ ] 原始資料可追溯來源、時間、版本及擷取批次。
- [ ] GitHub Actions 不繞過 `main` 的階段驗收；寫入流程有權限與併發限制。
- [ ] Git history 不因每日快照無限制膨脹；有版本化資料包保留策略。
- [ ] 分析結果明確區分事實、推論、未知與建議。
- [ ] 未經證實的資料量或市場預測不當作已驗證事實。
- [ ] 不宣稱所有展覽都能自動取得完整資料；部分成功、匯入與資料不足都有明確標示。
- [ ] 前端沒有 Token、API Key 或可寫入憑證；Dashboard 不被描述成能直接執行後端任務（總規範 §4.1）。
