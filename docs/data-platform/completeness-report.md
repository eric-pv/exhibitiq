# 完整度、缺漏與品質報告

> 工作項目：D2-09｜負責人：data｜程式：`etl/report.py`｜`python -m etl.report <資料包目錄> [--json]`

每個數字都是從資料包數出來的，**不估計**。結束碼：`0` 資料包通過驗證程式；`1` 未通過；`2` 讀不到。

- **完整度：** 取自 manifest（`complete` / `partial` / `unknown`），並列出官方筆數、已收集的 `listed` 參展紀錄數。官方筆數與收集數不同時，只陳述差異（`官方 − 收集`），不推測缺哪些。沒有官方筆數時明說「無法判斷完整度」。
- **計數：** 公司、參展紀錄（listed / removed）、來源、擷取批次（依狀態）、變更；依參展類型與查證狀態分組。
- **欄位覆蓋：** 公司與參展紀錄的選填欄位各有幾筆有值、幾筆缺（空字串、空陣列不算有值）。
- **缺漏（gaps）：** 與官方筆數的差異、合成資料聲明、未完全成功的擷取批次、未保存的快照。
- **品質旗標（只供人工檢視，不修改任何資料）：** 名稱僅法律型態不同的可能重複公司（不含已合併者）、沒有網站的公司、完全沒有展位資訊。

不包含：官方筆數的取得（需要來源，屬來源評估與匯入）、Dashboard 呈現（Eric 側讀取這份 JSON）。
